# Tracker — трекер привычек

Мобильное приложение для формирования полезных привычек и контроля их выполнения. Пользователь создаёт карточки-трекеры, отслеживает прогресс по дням и просматривает статистику.

Дизайн: [Figma](https://www.figma.com/design/owAO4CAPTJdpM1BZU5JHv7/Tracker?node-id=65-16056&p=f)

## Мой вклад

Проект реализован самостоятельно на основе технического задания. Помимо базового функционала, добавил ряд улучшений сверх ТЗ:

- Локализация интерфейса (русский / английский)
- Яндекс.Метрика для аналитики пользовательских действий
- Snapshot-тесты ключевых экранов
- Полноценный онбординг с page control

## Основной функционал

- Создание трекеров привычек (название, категория, расписание, эмодзи, цвет)
- Категории с возможностью создания, редактирования и удаления
- Календарь для просмотра трекеров по дате
- Поиск и фильтрация трекеров (все / на сегодня / завершённые / незавершённые)
- Статистика: лучший период, идеальные дни, всего завершено, среднее значение в день
- Тёмная тема (следует системным настройкам)

## Архитектура

Приложение написано на UIKit. Архитектура смешанная: часть модулей реализована по MVC, часть (в первую очередь статистика и работа с данными) вынесена в MVVM — по мере того как логика экранов усложнялась, для более честного разделения ответственности часть кода была отрефакторена под MVVM. Не претендую на единый архитектурный подход по всему проекту — это осознанный компромисс на этапе обучения, а не итоговый эталон.

## Технологии и инструменты

- UIKit, Auto Layout (без Storyboard / программная вёрстка)
- CoreData – локальное хранение трекеров и категорий
- GCD (DispatchQueue) — работа с многопоточностью 
- SPM — управление зависимостями
- Yandex Metrica SDK — аналитика
- XCTest / snapshot-тесты
- Локализация (Localizable.strings, RU/EN)
- Git

## Требования

- iOS 17.0+
- Xcode 15+

## Установка

```bash
git clone https://github.com/Gudleifre/Tracker.git
cd Tracker
open Tracker.xcodeproj
```
Зависимости через SPM подтянутся автоматически при первом открытии проекта.
